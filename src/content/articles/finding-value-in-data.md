Every analytics conversation eventually hits the same question: "Should we buy more tooling?" Almost always, the honest answer is no. The gap isn't in the stack — it's in what the existing stack is being asked.

## Start with a decision, not a dashboard

Dashboards are inventory; decisions are demand. Before building anything, name the decision a person will make differently because of this chart. If you can't, you're decorating, not analyzing.

## Three questions that surface hidden value

1. **What do we measure but never act on?** Dead metrics are a map of abandoned intentions — either kill them or find out why they stalled.
2. **Where do two teams disagree about a number?** Disagreements about definitions are where value leaks quietly, every single day.
3. **What would we do differently if this number doubled overnight?** If nothing changes, it's a vanity metric.

## Small wins compound

The organizations that get the most from their data aren't the ones with the biggest warehouses. They're the ones who close small loops quickly: one metric, one owner, one decision, one review. Then repeat.

Value isn't found. It's realized.
